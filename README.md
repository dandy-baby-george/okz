## Commands & Usage

All commands are registered as Discord Slash Commands (`/`). Simply type the command and press enter.

| Command | Category Label | API Ordering Parameter | Description |
| :--- | :--- | :--- | :--- |
| `/get` | `RECOMMENDED` | `featured` | Fetches a video from recommended listings. |
| `/hot` | `HOT` | `hot` | Fetches a video currently trending/hot. |
| `/top` | `TOP-RATED` | `toprated` | Fetches a top-rated video. |
| `/views` | `MOST-VIEWED` | `mostviewed` | Fetches a most-viewed video. |
| `/latest` | `LATEST` | `newest` | Fetches the most recently uploaded video. |
| `/random` | `RANDOM` | `random` | Fetches a video randomly selected from results. |
