## Commands & Usage

All commands are registered as Discord Slash Commands (`/`). Simply type the command and press enter.

| Command | Description |
| :--- | :--- |
| `/get` | Fetches a recommended video. |
| `/hot` | Fetches a currently trending/hot video. |
| `/top` | Fetches a top-rated video. |
| `/views` | Fetches a most-viewed video. |
| `/latest` | Fetches the most recently uploaded video. |
| `/random` | Fetches a video randomly selected from results. |
